# Dr Mirhelli Exam — نسخه 1

فایل `index.html` را در ریشه Repository گیت‌هاب قرار دهید.

این نسخه:
- به Supabase پروژه متصل است.
- ورود با Email/Password دارد.
- نقش `admin` و دانش‌آموز را از جدول `profiles` تشخیص می‌دهد.
- پنل اولیه متناسب با نقش نشان می‌دهد.
- هیچ Secret Key داخل فایل قرار نگرفته است.

بعد از تست موفق ورود، مرحله بعد: مدیریت کاربران، ساخت آزمون، سؤال‌ها، تایمر، پاسخ‌ها و کارنامه.
